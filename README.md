# 魔光鍵影 Playground

一個低調、純原生 JavaScript 的打字練習頁面。畫面上會出現幾個單詞，在時間內輸入並按 Enter 送出即可消除。支援日文與英文詞庫，並附有練習統計的「戰績」頁與可分享的成績圖片。

## 玩法

- 每次出現 3–5 個單詞，同時最多 10 個；單詞停留預設 30 秒，逾時會自動消失。
- 輸入內容後按 **Enter** 送出，完全符合就消除。**Esc** 清空輸入框，**↑ / ↓** 叫回之前送出的內容。
- **日文模式**：每個詞有上下兩行。可輸入下方英文，或用日文輸入法輸入上方假名本身（不接受羅馬拼音）。
- **英文模式**：只出現英文詞（自動過濾非英文）。`! ' ? -` 等符號可省略，`.` `,` 與空格必須輸入。可在設定中選擇是否區分大小寫。
- **計時模式**：限時 3 分鐘（可改為 1 或 5 分鐘）。**自由模式**：不限時間，閒置 15 秒會自動暫停，一有輸入就繼續。
- 切換到別的視窗會自動暫停。

## 戰績（Dashboard）

練習場次與累計時間、每詞平均用時、正確率、逾時比例、每分鐘消除數、連續練習天數、最近 20 場走勢、最近 14 天每日練習時間、最常打錯／最耗時／最常逾時的單詞 Top 10。可依語言與模式篩選，並可按「分享」產生帶使用者名稱的 PNG 成績圖。

## 設定

語言、模式與計時長度直接在「訓練場」頁面上方調整；「設定」頁有單詞停留時間、大小寫、淺色／深色主題、使用者名稱（留空會使用「光之戰士#xxxx」）。所有設定與練習紀錄都存在瀏覽器的 localStorage，不會上傳，也不會跨裝置同步。

## 執行

專案是純靜態檔案，不需要打包。因為使用 ES modules 並以 `fetch` 讀取 CSV，**必須透過 HTTP 伺服器開啟**（直接雙擊 `index.html` 不會運作）：

- VS Code 的 Live Server：對 `index.html` 按 Go Live。
- 或任何靜態伺服器，例如 `npx serve`。

部署到 GitHub Pages 時，選擇 `main` 分支的根目錄即可。

## 專案結構

```
index.html          頁面骨架
style.css           樣式（淺色／深色）
assets/icon.ico     網站圖示，也用於分享圖片
resources/          詞庫 CSV（欄位：id, 文字, 假名）
js/
  main.js           進入點：分頁切換、全域事件
  state.js          共用常數與狀態、設定與紀錄的讀寫
  words.js          CSV 解析與詞庫載入
  matcher.js        輸入比對（英文符號可省略、假名逐字比對）
  typing.js         輸入框處理：即時標示、送出歷史
  game.js           單詞生成、Enter 判定、場次、計時迴圈
  board.js          遊戲畫面：格子、HUD、覆蓋層
  settings.js       設定頁、主題、使用者名稱
  dashboard.js      Dashboard 與圖表
  share.js          分享圖片（canvas）
  util.js           共用小工具
```
